From scope to handover

A practical path to a tested system

  1. Review the inputs

    Send drawings, the bill of materials, room functions and available project files. For an existing system, include software versions and a description of the change or fault. Identify missing information before development begins.

  2. Agree scope and price

    Define programming, panel pages, DSP work, revisions and documentation. The estimate separates remote development, site testing and later project phases where needed. Agree fixed-price or time-and-materials terms and payment milestones in writing.

  3. Develop and test together

    Review user workflows and prepare for an approved deployment window. Customer IT authorizes access and network changes. A local technician handles wiring, listening checks and other physical tests that cannot be verified from source files alone.

  4. Deliver the agreed package

    Provide agreed source files, configurations, version notes and test results, subject to third-party licensing. Record outstanding site issues and follow-up work so the team taking over support knows what was tested and what remains.

Project questions

Before requesting an estimate

Can you work with a system outside Toronto?
Yes. We support English-language projects in Canada, the US, UK, Australia, New Zealand and Ireland, with worldwide remote delivery by agreement. Scope, authorized access and a shared testing schedule are confirmed first. Physical checks need someone at the site. On-site Wirewolf work is available in the GTA and Ontario.
Can an integrator subcontract programming to Wirewolf?
Yes. We can scope a programming package, documentation work or scheduled commissioning support alongside your installation team. The agreement defines responsibilities, customer communication, deliverables and acceptance tests.
Do you need existing source files?
For changes to an existing system, editable source files and compatible software are important. We review what is available before quoting. If files are missing, assessment or redevelopment may be needed. New systems can be developed from an agreed scope and equipment list.
How are commercial projects priced?
Hourly labour rates are CAD 115 for senior programming, CAD 95 for mid-level programming, CAD 90 for engineering and commissioning, and CAD 90 for GUI design, before applicable taxes. We agree the scope, rates and estimated hours before work begins. Fixed-price proposals are also available for an agreed scope. Other project costs are quoted separately.
